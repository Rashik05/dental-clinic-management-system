## Project Overview

The Dental Clinic Database Management System is a relational database designed to streamline clinic operations by managing patients, appointments, dentist schedules, insurance information, referrals, and payments. The project emphasizes data integrity, normalization, and efficient data retrieval through SQL while modeling realistic clinic workflows. :contentReference[oaicite:1]{index=1}

---

## Business Problem

Dental clinics manage large amounts of patient, appointment, and payment information. Without a well-designed database, maintaining accurate records, scheduling appointments, tracking insurance coverage, and generating reports becomes difficult.

This project was developed to design a normalized relational database that supports efficient clinic operations while maintaining data integrity and reducing redundancy. :contentReference[oaicite:2]{index=2}

## Database Design

The database consists of the following entities:

- Patient
- Dentist
- Appointment
- Insurance
- Payment
- Installment
- Dentist Schedule
- Patient Referral
- Patient Covered By Insurance

The schema was designed using ER modeling and normalized through BCNF to ensure data consistency and minimize redundancy. :contentReference[oaicite:3]{index=3}

---

## Normalization

The database satisfies:

- First Normal Form (1NF)
- Second Normal Form (2NF)
- Third Normal Form (3NF)
- Boyce-Codd Normal Form (BCNF)

This ensures the database is free from redundancy and maintains strong referential integrity. :contentReference[oaicite:4]{index=4}
